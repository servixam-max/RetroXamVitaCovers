# RetroXamVitaCovers

Carátulas (240x320 JPEG, calidad 88) para el launcher **RetroXam** de PS Vita.

- **16 sistemas, 1.847 carátulas**: NES, SNES, Game Boy, Game Boy Color, Game Boy Advance, Mega Drive, Mega CD, Sega 32X, PlayStation, Neo Geo, CPS-1, CPS-2, CPS-3, FBNeo, Nintendo 64 y OpenBOR.
- El launcher las **descarga solo** mientras navegas por la lista y las guarda en
  `ux0:/data/retroxam/covers/<sistema>/<juego>.jpg`
- Para tenerlas todas de golpe: descomprimir `RetroXamVita_Covers.zip` dentro de `ux0:/data/retroxam/`
- Base: libretro-thumbnails + ScreenScraper (completadas a mano las que faltaban).

Se genera/verifica con las herramientas del repo principal
[RetroXamVita](https://github.com/servixam-max/RetroXamVita).
